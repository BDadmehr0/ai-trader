# AI BTC Trader

سیگنال معاملاتی لحظه‌ای بیت‌کوین (پیش‌فرض: **BTC/USDT**) با تحلیل پیشرفته‌ی
چندچهارچوب‌زمانی (MTF)، همراه با موتور بک‌تست و یک وب‌پنل Flask.

## نصب

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

> اگر دسترسی به اینترنت / صرافی محدود است (مثلاً نیاز به پروکسی)، فایل
> `.env.example` را به `.env` کپی کنید و `PROXY_URL` را تنظیم نمایید.

## اجرا

### ۱) سیگنال لحظه‌ای — خرید / فروش / صبر (پیش‌فرض)

```bash
python main.py
# یا
python main.py signal
```

با هر اجرا، آخرین داده‌ی BTC/USDT گرفته می‌شود و برنامه با یک خروجی ساده و
قابل‌فهم می‌گوید: **خرید (BUY)**، **فروش (SELL)** یا **صبر (HOLD)**، همراه با
قیمت، سطوح حمایت/مقاومت، ورود/حد ضرر/اهداف و دلایل تحلیل.

### ۲) بک‌تست تاریخی

```bash
python main.py backtest
```

معاملات شبیه‌سازی‌شده در `trades.csv` و نمودار منحنی سرمایه در `equity_curve.png`
ذخیره می‌شود.

### ۳) وب‌پنل Flask

```bash
python main.py panel --port 5000
# و در مرورگر:
# http://localhost:5000
```

- صفحه‌ی اصلی `/`: سیگنال لحظه‌ای با کارت بزرگ خرید/فروش/صبر، سطوح معاملاتی،
  تحلیل چارچوب‌های زمانی و حمایت/مقاومت. (هر ۶۰ ثانیه خودکار به‌روز می‌شود.)
- صفحه‌ی بک‌تست `/backtest`: نتیجه‌ی شبیه‌سازی تاریخی.
- API: `GET /api/signal` خروجی JSON کامل سیگنال را می‌دهد.

## ساختار

```
analysis/       اندیکاتورها، سیگنال، سطوح، ریسک، استراتژی و موتور سیگنال زنده
backtesting/    موتور بک‌تست، متریک‌ها، آماده‌سازی MTF و خروجی
config/         تنظیمات (نماد، تایم‌فریم، ریسک، کارمزد، اهرم، ...)
data/           دریافت داده از صرافی + داده‌ی نمایشی آفلاین (data/cache)
webapp/         پنل Flask (قالب‌ها و استاتیک)
reports/        گزارش‌های کنسول و نمودار
main.py         رابط خط فرمان
```

## داده‌ی آفلاین / نمایشی

اگر صرافی در دسترس نباشد، برنامه به‌صورت خودکار از یک مجموعه‌داده‌ی ساخته‌شده
(سنتتیک) استفاده می‌کند تا کرش نکند. در این حالت در خروجی پیام
**«داده‌ی نمایشی (آفلاین)»** نشان داده می‌شود تا این اعداد با قیمت واقعی اشتباه
نشوند.
