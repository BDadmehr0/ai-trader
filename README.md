## یک تفاوت مهم دیگر

در README فعلی تو API این‌طور است:

```text
GET /api/signal
```

ولی Patch نسخه جدیدتر را پیشنهاد می‌دهد:

```text
GET /api/signal?symbol=ETH
GET /api/candles?symbol=ETH&tf=1h
```

همچنین این قابلیت‌ها را اضافه می‌کند:

* تغییر رمزارز از نوار بالا
* جستجو بین رمزارزهای USDT
* نمودار کندل‌استیک
* تغییر تایم‌فریم 15m / 1h / 4h
* نمایش Entry / Stop Loss / Targets روی نمودار

**فقط اگر این قابلیت‌ها واقعاً در `webapp` پیاده‌سازی شده‌اند، این قسمت README را اضافه کن.** چون README نباید قابلیتی را توضیح دهد که هنوز در کد وجود ندارد.

## بعد از اصلاح README

فایل reject را پاک کن:

```cmd
del README.md.rej
```

بعد وضعیت را بررسی کن:

```bash
git diff -- README.md
git status
```

اگر درست بود، هنوز commit نکن تا همه `.rej`ها را بررسی کنیم.

در آخر، وقتی همه merge شدند:

```bash
git add .
git commit -m "Apply patch changes"
git push
```

پس برای این فایل، **کل README را جایگزین نکن**؛ نسخه فعلی را نگه دار و فلوچارت را اضافه کن. سپس `README.md.rej` را حذف کن.
